# Sistem-Informasi-Kepegawaian
SIMPEG adalah website Sistem Informasi Kepegawaian berbasis PHP dan MySQL untuk mengelola data pegawai secara terpusat. Fitur utamanya: data pegawai, jabatan, dan departemen (tambah, ubah, hapus, cari), serta penggajian yang otomatis menghitung total gaji dari gaji pokok, tunjangan, dan potongan. Dashboard menampilkan ringkasan datanya.
